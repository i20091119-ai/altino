# 알티노 캠프 앱

2026 코딩앤메이커 with AI 캠프 「새온 로봇 캠프(알티노)」(11/22)에서 쓰는 태블릿 앱.
알티노 **라이트**(와 네오)를 블루투스(BLE)로 연결해, 수업 6개와 시험 경기장 5종을 한 앱에서 한다.

- 화면은 `webapp/` 의 HTML·JS 그대로이고, `android/` 가 이를 WebView 로 띄우면서 블루투스를 맡는다.
- 통신·안전 규칙(kit)은 「알티노 로봇학교」 앱(`i20091119-ai/2026.-altinoneoschool`)에서 가져왔다.

## APK 받기

`main` 에 올라가면 GitHub Actions 가 APK 를 만들어 **Releases** 에 올린다.
태블릿에서 Releases 의 `altino-camp-v1.0.N.apk` 를 받아 설치한다(출처를 알 수 없는 앱 허용 필요).
한 번 설치한 뒤에는 앱 홈의 **업데이트 확인**으로 새 버전을 받는다.

## 화면

| 파일 | 내용 |
|---|---|
| `index.html` | 캠프 홈 — 가족 이름, 경기장 5종, 수업 6개, 우리 가족 점수 |
| `c01.html` | ① 정지 — 전진 버튼 한 번만 눌러 정지선에 멈추기(단계별 속도 300·300·400·500) |
| `c02.html` | ② 표현 — 카드의 표정(도트 8×8)과 소리를 만들어 출력, **앱이 판정**(틀린 칸 2개까지 성공) |
| `c03.html` | ③ 암호 전달 — 카드 뽑기 + 신호 보내기(불빛·소리·도트 모양), 판정은 심판 |
| `c04.html` | ④ 센서 자율주행 — 손 따라오기(1~3단계), 손 없이 장애물 피하기(4단계) |
| `c05.html` | ⑤ AI 주행 — 태블릿 카메라로 손짓 4종을 가르치고 손짓으로 운전(인터넷 불필요) |
| `check.html` | 선생님용 점검 — 연결·모터·조향·소리·도트·LED 비트·센서 값 확인, 결과 복사 |
| `t01~t06.html` | 수업 6개(입학하기~손길 알아채기) — 로봇학교 앱에서 그대로 가져옴 |

경기장 화면 위쪽의 진행 바: **연습 / 도전**, 단계 4개(10·20·35·55점), 기회 3번, 4분.
도전에서 심판은 ⭕·❌ 버튼을 **꾹 눌러** 판정한다(②는 앱이 판정). 기록은 태블릿에 남지만 공식 기록은 심사표다.

## 알티노 라이트에서 아직 확인하지 못한 것

라이트의 프레임(보냄·받음 22바이트)은 오케스트라2 앱을 분석해 만든 것이고 **실물로 확인하지 못했다**.
`check.html`(홈 오른쪽 아래 「선생님용 점검」)에서 아래를 확인해 결과를 복사해 보낸다.

1. 연결되면 「받는 속도」가 0 이 아닌가 (0 이면 기종 단추를 바꿔 본다)
2. ▲▼ 로 앞뒤로 가는가, ◀▶ 로 앞바퀴가 맞는 쪽으로 꺾이는가, 최저 출발 속도
3. 소리 8음이 도~높은도로 들리는가
4. 도트 「화살표」가 위를 가리키는가(아니면 「방향 맞추기」)
5. LED 비트 1~128 을 하나씩 눌러 어느 등이 켜지는가 → 쓸 값을 「불빛 신호로 저장」
6. 손을 왼쪽 앞·가운데·오른쪽 앞에 대면 어느 센서(ir1~ir6) 값이 변하는가, 가까우면 커지는가 작아지는가

## 개발

```bash
npm install            # playwright (시험용)
node tools/serve.mjs   # http://localhost:8099/  — 브라우저에서는 가짜 로봇으로 동작
node tests/camp.mjs    # 화면·흐름 시험(스크린샷 tests/shots/)
```

- ⑤ AI 주행은 TensorFlow.js + MobileNet v1 0.25(둘 다 Apache-2.0)를 앱 안에 넣어 쓴다.
  `webapp/js/ai/mobilenet_data.js` 는 `tools/make_mobilenet.py` 가 만든다.
- 로봇은 `kit` 으로만 움직인다(누르는 동안만 `kit.hold`, 자율 동작은 `kit.run`). 화면이 가려지거나 창이 뜨면 kit 이 멈춘다.
